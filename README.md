<h2>This is the client repository for Sundouleia.</h2>
Sundouleia is a DataSync plugin for FFXIV that can be installed via Dalamud.

Sundouleia took inspiration from mares tech stack and identified ways the service as a whole could be improved.</br>
It had to be remade from the ground up, pivoting to a new architecture for its vision to be fulfilled.

Sundouleias new structure prioritizes micro-optimizations, efficiency, effectively instant response time, and near limitless scalability for all of its features.

For more information, visit: https://github.com/Sundouleia
