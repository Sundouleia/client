<h2>This is the client repository for Sundouleia.</h2>
<p>Sundouleia is a DataSync plugin for FFXIV that can be installed via Dalamud.</p>

<p>Sundouleia took inspiration from mares tech stack and identified ways the service as a whole could be improved.
It had to be remade from the ground up, pivoting to a new architecture for its vision to be fulfilled.</p>

<p>Sundouleias new structure prioritizes micro-optimizations, efficiency, effectively instant response time, and near limitless scalability for all of its features.</p>

For more information, visit: https://github.com/Sundouleia
